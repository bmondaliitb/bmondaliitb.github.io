Minimal Window Borders solves one small desktop problem: when window and background colors are close, it can be difficult to see where one surface ends and another begins. The extension adds a subtle border without introducing a large settings interface or visual clutter.

It is installed directly as a local GNOME Shell extension and can be enabled with the standard `gnome-extensions` command. The project is intentionally narrow—a good example of software where a short implementation and a clear installation path are enough.
