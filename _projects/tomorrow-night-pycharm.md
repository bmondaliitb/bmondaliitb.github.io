This project adapts the Tomorrow Night palette into a complete PyCharm color scheme. It covers Python first, then supplies useful defaults for JSON, YAML, HTML, XML, CSS, and JavaScript so switching file types does not break the visual hierarchy.

The repository includes both an importable `.icls` file and a script that packages the scheme as a JetBrains plugin JAR. The result can therefore be tried directly or installed through the IDE's plugin workflow.

This is currently maintained as a local utility without a public repository.
